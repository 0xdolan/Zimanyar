# Zimanyar · زمانیار

**Offline grammar checker and teacher for Kurdish: Sorani (`ckb`) and Kurmanji (`kmr`).** Zimanyar finds mistakes, explains why they are wrong, suggests and applies fixes, autocompletes, and links every finding to the lesson that teaches the rule. It will ship as a browser extension (Chrome, Firefox, Safari), a Linux desktop app, a command-line tool, a language server and a website.

> Status: specification stage. The full product requirements are in **[PRD.md](PRD.md)**; development happens on the `develop` branch.

Built on the linguistic engine of [zimankit](https://github.com/0xdolan/zimankit).
