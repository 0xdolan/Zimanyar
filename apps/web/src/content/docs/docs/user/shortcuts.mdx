---
title: Keyboard shortcuts
description: Every action in the checker works from the keyboard.
sidebar:
  order: 2
---

| key | where | does |
|---|---|---|
| Alt+Enter | in the text | opens the finding at the caret, or the next one |
| Esc | in the text or a card | closes the card |
| Tab | in a card | moves through the suggestions and actions |
| Enter | on a suggestion | applies it |
| Down, Up | while words are offered | moves through the words |
| Tab | while words are offered | takes the chosen word, or the first |
| Enter | while words are offered | takes a word once one is chosen; otherwise ends the line |
